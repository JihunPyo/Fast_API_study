# FastAPI 스터디

FastAPI로 백엔드 개발의 기초를 다지는 것을 목표로 하는 그룹 스터디입니다.
교재의 실습을 그대로 따라가는 것에 그치지 않고, 매주 별도의 Blog 앱을 스스로 설계·구현해보며 이해도를 점검합니다.

- **교재:** 코딩 자율학습 FastAPI 파이썬 백엔드 개발 입문 (신동현 저)
- **방식:** 주 1회 대면, 회당 2시간 (장소는 그때그때 카페 / 동방 / 강의실 중 공지)
- **기간:** 6주 목표 (필요시 최대 8주로 조정)

## 커리큘럼

| 주차 | 장 | 내용 | 비고 |
| --- | --- | --- | --- |
| 1주차 | 1~2장 | FastAPI 개요, 실습환경 설정, HTTP·경로/쿼리 파라미터·Pydantic | |
| 2주차 | 3장 | 기본 CRUD (Todo 앱) | |
| 3주차 | 4장 | 데이터베이스와 ORM (MySQL 설치, SQLAlchemy) | MySQL 설치는 모임 전에 완료 |
| 4주차 | 5장 | 회원가입 | |
| 5주차 | 6장 | 로그인과 인증 (세션 + JWT) | 분량 최다, 필요시 2주로 분리 |
| 6주차 | 7장 | 고급 기능 + 전체 마무리 | Lifespan·DI·백그라운드 태스크·파일 처리 |

## 매주 과제

1. 주차별 학습 내용 정리하여 업로드 (노션 등 원하는 방식)
2. **본문 트랙** — 교재 Todo 앱 실습 코드 직접 타이핑 (복붙 금지)
3. **셀프체크 트랙** — Blog 앱을 정답 보지 말고 스스로 구현 후 비교
   - 2주차: Article CRUD 구현
   - 3주차: Blog를 DB/ORM으로 전환
   - 4주차: Blog에도 회원가입 추가 (자율 설계)
   - 5주차: 댓글 세션 로그인 구현 + Blog에 JWT 추가 (JWT는 자율 설계)
   - 6주차: Blog에 파일 업로드 등 7장 기능 적용 (자율 설계)

실습 코드는 깃허브에 공유해주세요.

## 폴더 구조

최상위 폴더 아래에 각자 폴더를 하나씩 만들고, 그 아래에 주차별로 `todos_wk1`, `blog_wk1` 식으로 폴더를 나눠서 push합니다.

```
fastapi-study/  (깃허브 레포 이름)
│
├── pyo/  (본인 이름 or 닉네임)
│   ├── todos_wk1/  (1주차)
│   │   ├── main.py
│   │   ├── schema/
│   │   └── ...
│   │
│   ├── todos_wk2/  (2주차)
│   │   ├── main.py
│   │   ├── schema/
│   │   └── ...
│   │
│   ├── blog_wk2/  (Blog 셀프체크 - 2주차부터)
│   │   ├── main.py
│   │   ├── models.py
│   │   ├── schema/
│   │   └── ...
```

## 모임 진행 순서 (120분)

| 순서 | 활동 | 시간 | 내용 |
| --- | --- | --- | --- |
| 0 | 과제 확인 | 5분 | 과제 업로드 했는지 확인 |
| 1 | 랜덤 발제 | 20분 | 무작위로 뽑힌 1명이 이번 주 내용 설명, 나머지는 중간중간 질문 |
| 2 | 질문 취합·선별 | 5분 | 못 푼 질문 + 준비해온 질문 전부 취합 → 투표로 3~4개 선정 |
| 3 | 질문 토론 | 55분 | 선정된 질문당 개별 고민 5분 + 공유토론 8~10분 |
| 4 | 코드 비교 | 30분 | Blog 구현 서로 비교 → 마지막에 교재 정답과 비교 |
